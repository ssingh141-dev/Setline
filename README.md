# Setline

A comms app for commercial and photo shoots: role-based chat, push-to-talk walkie for crew, client frame approvals tied to the shot list, call sheet info and a read-only wrap.

## What's here so far

- `reference/prototype.html`: the clickable prototype. Open it in any browser. Use the role switcher to see what each person sees.
- `supabase/migrations/20261116000000_init.sql`: the proposed database schema and permission rules. Not applied anywhere yet.

App code starts after the plan is approved. Setup steps for non-engineers will live in this README.
